NDA 4X STRATEGY

Работаю в качестве Unity-разработчика клиентской части над многопользовательской мобильной 4X стратегией со строительством базы, управлением ресурсами, прокачкой героев и тактическими боями.

Из-за NDA не могу раскрыть детали.

Применял следующие подходы и технологии:
🔹 Clean Architecture в качестве архитектурного подхода
🔹 VContainer в качестве Dependency Injection фреймворка
🔹 MessagePipe в качестве шины данных для decoupled-связи
🔹 UniTask для использования async/await
🔹 R3 для реактивного программирования
🔹 PlayFab для backend сервисов, конфигов и аналитики
🔹 DOTS(ECS)
🔹 UI Toolkit для UI
🔹 FMOD в качестве аудио системы
🔹 NSubstitute и NUnit для создания unit тестов

Примеры задач, которые выполнял:
🔹 Разработал диалоговую систему персонажей
🔹 Работал над системой снаряжения игрока - производство, улучшение, разборка игровых предметов и материалов для их создания
🔹 Создал инструмент массового импорта контента, который позволяет экономить десятки часов работы техартистов (в два клика в проект добавляются 2d текстуры, иконки, 3d модели с авто-применением пресетов, с созданием атласов, с авто-созданием префабов игровых сущностей, с авто-добавлением их на сцены и в Addressables).
🔹 Создал инструмент выгрузки данных из google sheets, что ускорило проверку баланса в 2 раза и экономит часы на создании конфигурационных файлов (из гугл таблиц, создаваемых и расширяемых гейм дизайнерами, выгружаются данные баланса и автоматически создаются Scriptable Objects, используемые в коде).
🔹 Создал инструмент для оптимизации применения теней в игре
🔹 Создавал GUI интерфейсы с помощью Unity UI Toolkit по созданной арт-отделом верстке в figma
🔹 Создавал unit-тесты с покрытием кода >70%, чтобы снизить до 0 появление критических багов в продакшене

🔹 Создал аудио систему с фоновой музыкой и звуковыми эффектами, полностью подобрал и настроил звук в игре
🔹 Внедрил полную локализацию для русского, английского, турецкого используя Unity Localization

WASTELAND IDLE ARCADE

Участвовал в роли главного Unity и C# разработчика в проекте по созданию мобильной игры в жанре Idle Arcade.

Игра включает системы перемещения игрока, прогрессии, управления ресурсами, система врагов, а также игровой цикл, разработанные с учетом масштабируемости.

Разработал архитектуру проекта, StateMachine для управления жизненным циклом игры:
GameRunner -> BootstrapState -> LoadProgressState -> LoadLevelState -> GameLoopState

Реализованные системы:
🔹 Система добычи ресурсов (Loot System) с событийной моделью: LootSpawner, BuildingProduce
🔹 Система прогресса игрока с централизованным хранением данных (PersistentProgressService)
🔹 Система врагов с различным поведением (патрулирование, обнаружение и преследование игрока, атака, потеря игрока и прекращение преследования, выпадение лута)
🔹 Аудио система с фоновой музыкой и звуковыми эффектами

Применённые паттерны:
🔹 State Machine — управление состояниями игры (GameStateMachine)
🔹 Abstract Factory — создание игровых объектов (GameFactory, UIFactory)
🔹 Service Locator — доступ к сервисам (AllServices)

Особенности:
🔹 Модульная архитектура для лёгкого масштабирования
🔹 Чистый и поддерживаемый код с современными паттернами программирования
